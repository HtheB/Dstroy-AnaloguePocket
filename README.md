# Dstroy for Analogue Pocket

A port of Dstroy, the Bomberman-style maze battle game, for Analogue Pocket.
Original game by Fully Bugged Software for MSDOS

## Download and install

1. Open **Releases** on this repository.
2. Download the attached `HtheB.Dstroy_*.zip` file.
3. Extract the ZIP contents to the root of your microSD card.
4. Keep the `Assets`, `Cores`, and `Platforms` folder structure intact.
5. Start Dstroy from the Pocket’s **openFPGA** menu.

Requires Analogue OS 2.2 or newer.

## Features

- Adventure and Battle modes
- Up to four players when docked
- Two-player mode on a single handheld
- Multiple languages
- Saved settings and Adventure progress
- Analogizer support

## Handheld controls

For two-player handheld mode:

- Player 1: D-pad to move, L to drop bombs
- Player 2: A/B/X/Y to move, R to drop bombs
- Select: Back

## Updates

Download the latest release and copy its contents over the existing installation.
Keep your `Saves` folder to preserve progress and settings.
